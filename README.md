# ずぼら16タイプ診断所（第77回駒場祭・企画ID 428）

来場者が自分のスマホで27問に答え、ずぼらタイプ・ずぼら度・偏差値を一枚絵で受け取る静的Webアプリ。
ビルド不要。外部のCDNやWebフォントは読み込まない（会場の通信が悪くても動くように）。

## 使い方

| URL | 用途 |
|---|---|
| `/` | 来場者用。出題順はシャッフル、Z-15 だけ最後に固定 |
| `/?staff=1` | スタッフ用。紙の回答用紙と同じ順番（`js/questions.js` の `PAPER_ORDER`）で並ぶ |
| `?test=1` を付ける | 記録に「テスト」の印を付ける（動作確認のとき） |

## ファイル

| ファイル | 中身 |
|---|---|
| `js/questions.js` | 設問27問、逆転の有無、紙の順番 |
| `js/types.js` | 16タイプの名前と説明文 |
| `js/config.js` | 年ごとに変える値（偏差値の μ・σ、記録先の URL、イラストを置いたタイプ、企画情報） |
| `js/logic.js` | 採点と判定（画面に依存しない） |
| `js/card.js` | 結果の一枚絵（1080×1350 の PNG）を描く |
| `js/record.js` | 匿名の回答記録。失敗しても診断は止めない |
| `js/app.js` | 画面の動き |
| `gas/` | 記録を受け取る Google Apps Script（スプレッドシートに1行ずつ書く） |
| `fonts/` | Zen Maru Gothic（SIL OFL 1.1）を使う文字だけに絞ったもの |
| `tools/subset_fonts.py` | フォントを作り直すスクリプト。**設問や説明文の文字を変えたら実行する** |
| `tests/` | 採点のテスト |

## 判定のルール

- 回答は左端「そう思う」が6点、右端「そう思わない」が0点。逆転項目は 6 − 回答値。
- 各軸は3問の合計（0〜18点）。**10点以上を高得点側、9点以下を低得点側**とする。
- 動物は 着手(A4)×範囲(A2)、バリエーションは 人目(A1)×未来(A3)。
- ずぼら度（表示）＝ 10 ＋ Z-1〜Z-15 の合計（10〜100%）。
- 偏差値 ＝ 50 ＋ 10 ×（素点 − μ）÷ σ。20〜80 に丸める。μ・σ は `config.js`（**公開データからの推定値**。根拠は同ファイルのコメント）。

## イラストの差し替え

16タイプ分を `assets/types/{タイプID}.webp`（600×600、背景透明）で置いている。元の画像は Google ドライブの「ずぼら16イラスト」フォルダ。
差し替えるときは同じ名前で置き換える。`config.js` の `ILLUSTRATIONS` から外したタイプは「イラスト準備中」の枠が出る。

## テスト

```bash
node --test
```

画面の確認はローカルで `python3 -m http.server` を立ててスマホ幅で開く（`file://` では動かない）。

## 回答記録（Apps Script）

- プロジェクト：「ずぼら16タイプ診断所_回答記録」 scriptId は `gas/.clasp.json`
- 最初に一度、エディタで `setup` を実行して承認する（記録用スプレッドシートが作られる）
- コードを変えたら `cd gas && clasp push --force` のあと、既存のデプロイを更新する：
  `clasp create-deployment -i AKfycbxvisfnuhw1GRnsxjgtwrRsMuwxJYWWa9SUpEUs3E1ELSkiQhYj2SOyhGl3EWql_zHW -d "説明"`
  （新しいデプロイを作ると URL が変わるので、`config.js` の `RECORD_ENDPOINT` も直す）
